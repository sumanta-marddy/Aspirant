# Free MCQ Mock Test Generator

Ye app bilkul free modules se bana hai.

## Pydroid 3 me install

1. Pydroid 3 open karo
2. Terminal open karo
3. Ye command run karo:

```bash
pip install flask PyPDF2 werkzeug
```

4. Project folder me jao:

```bash
cd free_mcq_mock_app
```

5. App run karo:

```bash
python app.py
```

6. Browser me open karo:

```text
http://127.0.0.1:5000
```

## Features

- Aspirant signup/login
- PDF upload
- Text notes paste
- Automatic MCQ generation
- Mock test
- Timer
- Score
- Test history
- No paid API
- No OpenAI API
- No Firebase required in this first free version

## Important

Ye rule-based MCQ generator hai. Matlab paid AI jaisa perfect question nahi banega, lekin notes/PDF se practice ke liye kaam karega.
